# Project guide for AI-assisted contributions

Read README.md, CONTRIBUTING.md and the relevant chapter before editing.
This project combines a dependency-free static atlas with a separate NumPy lab.

## Useful checks

```bash
node --test tests/atlas.test.js
python -m unittest discover -s tests -p 'test_*.py' -v
python scripts/check_site.py
python scripts/build_site.py
```

## Scientific accuracy

Explain assumptions, units, basis conventions and boundary conditions. Derive
results in original language and cite primary references. Check numerical work
against an analytic solution or a documented convergence/conservation criterion.
Do not claim a complete curriculum, independent review, adoption, downloads,
contributors, releases or grant eligibility without evidence.

## Architecture

Keep the browser application static and accessible without accounts. Progress
is local convenience data, never an authorization mechanism. Read
docs/AUTHENTICATION.md before changing storage or workflows. Never add real keys,
tokens, account emails or private data to code, docs, examples or generated assets.
The Pages artifact is the allowlisted `_site` directory generated by
scripts/build_site.py, not the whole repository.

Preserve stable paper IDs and the separation between existing content and
planned work. Keep application preparation in docs/CLAUDE_APPLICATION.md distinct
from educational content. Report actual checks and remaining limitations.
